# 聚焦练习室 · Focus Lab

一个打开浏览器就能使用的中文练习工具，包含舒尔特方格、呼吸重置和颜色干扰挑战。支持电脑和手机，无需注册账号。

## 在线体验

### [点击打开舒尔特方格 →](https://yomaicl825-debug.github.io/Focus/)

可以收藏这个网址，或直接分享给朋友。手机也可以通过浏览器访问。

## 功能介绍

### 舒尔特方格

支持 **3×3、4×4、5×5、6×6、7×7、8×8**，共 9～64 个目标。

| 模式 | 规则 |
| --- | --- |
| 顺序数字 | 按 1 → N 依次点击 |
| 倒序数字 | 从最大数字开始，按倒序点击 |
| 红蓝交替 | 红色数字递增、蓝色数字递减，交替点击 |
| 字母方格 | 按 A、B、C…的顺序点击；超过 Z 后继续 AA、AB… |

支持八种排布：

| 排布 | 特点 |
| --- | --- |
| 标准方格 | 整齐排列的经典方格 |
| 交错方格 | 行列错位排列 |
| 不规则舒尔特 | 将整块区域切分为不规则拼块 |
| 圆环舒尔特 | 环形扇区排列，开始后各环缓慢交替旋转 |
| 蜂窝舒尔特 | 相贴的正六边形 |
| 全随机舒尔特 | 每次点击后全盘重排，包括已经点过的目标 |
| 圆形不规则 | 在圆形区域内散点排列 |
| 动态舒尔特 | 每次找对目标后，重新排列剩余内容 |

练习时显示当前目标、用时、失误次数和完成进度，完成后保存成绩。

### 呼吸重置

60 秒的节奏练习，跟随圆环进行 **4 秒吸气 / 4 秒呼气**。

### 颜色干扰

30 秒挑战：忽略文字的含义，选择**文字实际显示的颜色**，记录正确次数。

### 训练记录

舒尔特方格和颜色干扰的成绩保存在当前浏览器中，最多保留最近 **30 条记录**。方格页面还会显示相同模式、数量和排布在保留记录中的最佳用时。

## 如何使用

1. 打开 [在线页面](https://yomaicl825-debug.github.io/Focus/)。
2. 选择方格模式、目标数量和排布样式。
3. 查看上方的“当前目标”，依次点击对应数字或字母；首次点击方格时开始计时。
4. 完成全部目标后查看成绩，点击“再来一局”继续练习。
5. 想重新开始时，点击“重新排列”。

电脑端通过左侧导航切换练习，手机端通过底部导航切换。“训练记录”中可以查看已保存的成绩。

> 切换方格模式、数量或排布会重新开始当前一局。

## 本地运行

下载本仓库的 `index.html`，用现代浏览器打开即可使用，无需安装依赖或执行构建命令。文件中的 HTML、CSS 和 JavaScript 已整合在一起，下载后可在本地离线打开。

## 技术实现

- 原生 HTML、CSS、JavaScript
- CSS Grid 与 SVG 实现多种方格排布
- 响应式布局，适配电脑和手机
- 使用浏览器 `localStorage` 保存成绩
- 使用 GitHub Pages 发布静态页面

## 数据说明

训练记录保存在当前设备、当前浏览器的网站存储中，不提供账号或跨设备同步。清除网站数据、切换浏览器或使用无痕模式时，记录可能无法保留；在线页面与本地文件的记录也不共享。
